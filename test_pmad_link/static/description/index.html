🔁 Core Functional Capabilities

🛒 Order Synchronization

  • Import marketplace orders into Odoo
  • Automatic customer creation
  • Channel-wise order mapping
  • Supports COD & prepaid workflows
  • Invoice PDF and shipping label attached to the Sale Order

📦 Product & SKU Management

  • SKU mapping between EasyEcom & Odoo
  • Barcode synchronization
  • Product consistency validation

🚚 Inventory & Warehouse Sync

  • Stock updates from EasyEcom to odoo
  • Warehouse-level inventory management across child companies with separate GST numbers
  • Scheduled sync using Odoo cron jobs
  • Manual sync for debugging & testing

  • No forced accounting customization
